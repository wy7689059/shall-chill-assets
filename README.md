# Shall Chill model assets

Unmodified Google MediaPipe MagicTouch int8 v1 model, split into four binary parts for distribution. Reassemble in part-number order and verify the full SHA-256 in `model-manifest.json`.

Model and runtime provenance: https://storage.googleapis.com/mediapipe-models/interactive_segmenter_v2/magic_touch/int8/1/interactive_segmentation.task
